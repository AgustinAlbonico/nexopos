Remitos electrónicos / COT — qué se reutiliza y qué construir

Base: módulo fiscal de Yomemimo (AFIP Factura A/B) · Destino: sistema simple para transporte de arena

Veredicto: Se puede reutilizar la autenticación AFIP (WSAA + certificados + homologación/producción). El flujo de facturas (CAE / WSFE) no sirve para remitos. COT es de ARBA, no de AFIP.

Qué hay hoy en Yomemimo

PiezaWSAA (login con certificado) + WSFEv1 (emisión Factura A/B/C con CAE)
AmbientesHomologación y producción (certs, URLs y tokens separados)
No existeRemitos, COT, guía minera, carta de porte

✓ Reutilizar

  • Login WSAA (TRA firmado, token/sign)
  • Gestión de certificados .crt/.key
  • Switch homologación ↔ producción
  • Patrón de config fiscal (CUIT, PV, UI)
  • Idea de PDF digital del comprobante

✗ No reutilizar / construir nuevo

  • Emisión FECAESolicitar / CAE / QR factura
  • Acoplamiento a ventas / IVA / Factura A-B
  • Remito con CAI (RG 1415 / 5678) + peso de carga
  • COT ARBA (si ruta PBA/adheridas y ≥4.500 kg)
  • Alta de viaje: origen, destino, patente, kg

Aclaraciones clave

Remito digital Documento de traslado genérico. Usa CAI (no CAE). Puede ser PDF; no usa el WS de facturas.
Remito electrónico ARCA Webservices por rubro (carne, azúcar, harina…). No hay uno genérico para arena.
COT Código de ARBA para amparar el transporte. Obligatorio por peso/valor y jurisdicción. Se evita solo con docs equivalentes (ej. guía minera).

MVP sugerido: viaje (peso + ruta + camión) → remito digital con CAI → COT ARBA si aplica → PDF e historial. Validar con el contador del cliente si corresponde guía minera u otra exención de COT.
