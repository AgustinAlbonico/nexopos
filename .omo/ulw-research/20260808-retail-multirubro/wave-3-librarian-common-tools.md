# Wave 3 — Herramientas retail comunes

## Mínimos
- Import: stable key, staging/preview, errors/duplicates, explicit commit and recovery/undo.
- Labels: template, supported printer/profile, preview/calibration, batch queue.
- Stocktake: named snapshot session, count, variance, review, approval/reconcile.

## Diferenciadores
- Import rollback and duplicate strategy.
- Label queues/PO-driven print/calibration.
- Partial/cycle count, multi-device count, reason/shrinkage analytics.

## Fuentes
- Square import/labels/full count docs.
- Lightspeed import/labels/inventory count docs.
- Shopify product CSV/labels/inventory adjustment docs.
- Odoo cycle count docs.
- ERPNext stock reconciliation/raw printing docs.

## EXPAND
- none — vendor set saturated.

## CLAIMS
- These three capabilities are common retail infrastructure and should precede several vertical extensions.
